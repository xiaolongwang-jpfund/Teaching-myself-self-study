# 第 5 章第 5 节：字符串

人使用计算机，通过程序实现人机交互。但是人使用的是文字，计算机只“认识”二进制数字。于是，处理字符串是计算机完成的主要工作任务。

## 字符串

**字符串（string）**，就是一段文字数据。

- **一个字符串**由 0 个或者多个字符构成。
- **空字符串**的值是`None`。

## 字符码表的转换

**字符码表**，可以理解为一张“字符和编号的对照表”：它为字符分配编号，让计算机能用数字表示文字。

截至目前，公布的 Unicode 17.0 版本的码表中，共收录了 159,801 个已编码字符。

- 用于把**单个字符**转换成**码值**的函数是`ord()`。
- 用于把**一个整数码值**转换成**单个字符**的函数是`chr()`。

## 字符串的标识

标识一个字符串有四种方式：

1. 用单引号`'xxx'`
2. 用双引号`"xxx"`
3. 用三个单引号`'''xxx'''`
4. 用三个双引号：`"""xxx"""`

四种写法定义的是同一种数据类型`str`；单引号和双引号常用于一行，三引号常用于多行。

## 字符串与数值之间的相互转换

由**数字组成的字符串**，可以转换成**数值**。

- `int()`**只能**用于转换整数。
- `float()`用于转换浮点数字。

同样的，数字也可以转换成字符串。

- `str()`可以将数字转换成字符串。

```Python
number = 123456
str(number)
```

输出的结果是：
`'123456'`，其中数字左右两边的单引号`'`是作为字符串的标识使用的。

### 一个有意思的内建函数`input()`

`input()`的功能是**接收用户的键盘输入**，然后将用户键盘输入的结果作为字符串返回。
它可以接收一个字符串**作为参数**，在接收用户的键盘输入之前，`input()`会把这个字符串参数，作为给用户的提示语输出到屏幕上。

- 这个参数是**可选参数**，如果直接写`input()`，就表示不提供参数，在要求用户输入的时候就不会显示提示语。

## 转义符

有些字符不能直接照着“看起来的样子”写进字符串，或者需要用一种写法让\`Python\`知道它们该怎么解释。因此，转义符解决的是**如何在字符串中表示字符**的问题。
**转义符（Escaping Character）**也被称为“脱字符”。它放在某些字符前面，会改变这些字符的含义或表示方式。

转义符有如下几种使用方式：
1. 字符串里的引号要避免和外层引号冲突。例如，外层用单引号时，内部的单引号可以写成`\'`:
  - 例如：`it\'s fine`，也可以直接换用双引号：`"it's fine"`

2. 要在字符串中表示反斜杠本身，要写`\\`
3. 记住两个常用转义序列：
  - `\n`表示换行；
  - `\t`表示制表符；
它们都是字符串里的特殊字符。

**反斜杠让字符串里的字符“按另一种方式解释”**。
